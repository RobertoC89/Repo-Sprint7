# Panel de Control - Análisis de Vehículos Usados en EE.UU.

Esta aplicación web interactiva fue desarrollada con **Streamlit** y **Plotly Express** para explorar y visualizar un conjunto de datos sobre anuncios de venta de coches en Estados Unidos.

## Enlace de la aplicación en vivo
- **URL en Render:** https://repo-sprint7-2.onrender.com/
